# SAP CPI -- HTTP to Mail & Mail to Mail Integration

## Overview

This repository demonstrates two practical integration scenarios using
**SAP Cloud Platform Integration (SAP CPI)**.

-   **HTTP to Mail:** Receives HTTP requests and sends the message
    content through email.
-   **Mail to Mail:** Retrieves incoming emails from Gmail and sends the
    processed email content using the Mail Receiver adapter.

------------------------------------------------------------------------

## 1. HTTP to Mail Integration

### Description

The HTTP to Mail integration demonstrates how SAP CPI receives an HTTP
request from an external application and sends the received message as
an email using the Mail Receiver adapter.

An external application sends data to SAP CPI through an HTTP endpoint.
SAP CPI processes the incoming request and sends an email to the
configured recipient using SMTP.

### Architecture

``` text
External Application / Postman
             |
             v
        HTTP Sender
             |
             v
      SAP CPI Integration
             |
             v
      Content Modifier
             |
             v
       Mail Receiver
           (SMTP)
             |
             v
           Gmail
```

### Adapters Used

  Adapter   Type       Purpose
  --------- ---------- ---------------------------------------------------
  HTTP      Sender     Receives HTTP requests from external applications
  Mail      Receiver   Sends emails to the configured email address

### Components Used

  Component               Purpose
  ----------------------- -----------------------------------------
  HTTP Sender Adapter     Accepts incoming HTTP requests
  Content Modifier        Modifies message body and headers
  Mail Receiver Adapter   Sends emails using SMTP
  Security Material       Stores email authentication credentials

### HTTP Sender Adapter Configuration

  Parameter      Configuration
  -------------- ---------------------------------------
  Adapter Type   HTTP
  Direction      Sender
  Purpose        Receives incoming HTTP requests
  Endpoint       Generated by SAP CPI after deployment

### Content Modifier

The Content Modifier is used to prepare or modify the message before
sending it through the Mail Receiver adapter.

It can be used to: - Set custom message bodies. - Create or modify
message headers. - Define exchange properties.

### Mail Receiver Adapter Configuration

  Parameter         Configuration
  ----------------- -----------------------------
  Adapter           Mail
  Protocol          SMTP
  SMTP Server       `smtp.gmail.com`
  Port              `587`
  Proxy Type        Internet
  Protection        STARTTLS Mandatory
  Authentication    User Name/Password
  Credential Name   Configured Gmail credential

### Security Configuration

-   Gmail 2-Step Verification enabled.
-   Gmail App Password used for authentication, where supported and
    permitted.
-   Credentials maintained in SAP CPI Security Material.

### Testing

1.  Deploy the integration flow.
2.  Open Postman.
3.  Select the HTTP method configured in the sender endpoint.
4.  Enter the deployed SAP CPI endpoint URL.
5.  Configure the required authentication.
6.  Enter a sample message in the request body.
7.  Send the HTTP request.
8.  Verify the email in the destination Gmail inbox.
9.  Check the message processing status in SAP CPI Message Monitor.

### Expected Result

The HTTP request received by SAP CPI is processed and delivered as an
email to the configured Gmail account.

## 2. Mail to Mail Integration

### Description

The Mail to Mail integration demonstrates how SAP CPI retrieves incoming
emails from a Gmail mailbox and sends the processed email content to a
configured recipient.

The Mail Sender adapter connects to Gmail using IMAP to retrieve
incoming emails. SAP CPI processes the message and sends it through the
Mail Receiver adapter using SMTP.

### Architecture

``` text
         Gmail
    (Incoming Email)
             |
             v
       Mail Sender
           (IMAP)
             |
             v
      SAP CPI Integration
             |
             v
      Mail Receiver
           (SMTP)
             |
             v
         Gmail
    (Outgoing Email)
```

### Adapters Used

  Adapter       Type       Purpose
  ------------- ---------- --------------------------------------
  Mail (IMAP)   Sender     Retrieves incoming emails from Gmail
  Mail (SMTP)   Receiver   Sends outgoing emails through Gmail

### Components Used

  Component               Purpose
  ----------------------- -----------------------------------------
  Mail Sender Adapter     Reads incoming emails from the mailbox
  Mail Receiver Adapter   Sends emails to the destination mailbox
  Scheduler               Checks the mailbox periodically
  Security Material       Stores Gmail authentication credentials

### Mail Sender Adapter Configuration (IMAP)

The Mail Sender adapter retrieves incoming emails from the Gmail
mailbox.

  Parameter                Configuration
  ------------------------ -----------------------------
  Adapter                  Mail
  Protocol                 IMAP
  Server                   `imap.gmail.com`
  Port                     `993`
  Proxy Type               Internet
  Protection               IMAPS
  Authentication           Plain User Name/Password
  Credential Name          Configured Gmail credential
  Folder                   INBOX
  Selection                Only Unread
  Post-Processing          Mark as Read
  Max. Messages per Poll   20

### Scheduler Configuration

  Parameter   Configuration
  ----------- ----------------
  Schedule    Recurring
  Frequency   Every 1 minute

The scheduler periodically checks the Gmail inbox for eligible unread
messages.

### Mail Receiver Adapter Configuration (SMTP)

The Mail Receiver adapter sends the processed email content.

  Parameter         Configuration
  ----------------- ---------------------------------
  Adapter           Mail
  Protocol          SMTP
  Server            `smtp.gmail.com`
  Port              `587`
  Proxy Type        Internet
  Protection        STARTTLS Mandatory
  Authentication    Plain User Name/Password
  Credential Name   Configured Gmail credential
  From              Configured Gmail address
  To                Configured Gmail address
  Subject           Email forwarded through SAP CPI
  Mail Body         `${in.body}`

### Security Configuration

-   Gmail 2-Step Verification enabled.
-   Gmail App Password used for authentication, where supported and
    permitted.
-   Credentials maintained in SAP CPI Security Material.
-   IMAPS used for secure incoming email communication.
-   STARTTLS used for secure outgoing email communication.

### Processing Configuration

**Selection: Only Unread**

CPI retrieves only unread emails from the configured mailbox.

**Post-Processing: Mark as Read**

After successful processing, the original incoming email is marked as
read to prevent it from being picked up again during subsequent polling
cycles.

Other available post-processing options may include deleting the
processed email, depending on adapter configuration.

### Testing

1.  Deploy the integration flow.
2.  Send an email to the configured source Gmail account from another
    email account.
3.  Wait for the configured polling interval.
4.  CPI checks the Gmail inbox.
5.  The Mail Sender adapter retrieves the unread email.
6.  CPI processes the email.
7.  The Mail Receiver adapter sends the configured email content.
8.  Verify the email in the destination Gmail inbox.
9.  Check the message processing status in SAP CPI Message Monitor.

### Expected Result

SAP CPI successfully retrieves an incoming email through IMAP and sends
the processed email content through SMTP.

## 4. Email Protocols and Ports

  Protocol             Port   Purpose
  -------------------- ------ --------------------------------
  IMAP                 143    Retrieves emails
  IMAPS                993    Securely retrieves emails
  SMTP                 25     Mail server-to-server transfer
  SMTP with STARTTLS   587    Secure email submission
  SMTPS                465    SMTP with implicit TLS
  POP3                 110    Retrieves emails
  POP3S                995    Securely retrieves emails

### IMAP

Internet Message Access Protocol.

Used by the Mail Sender adapter to retrieve emails from a mailbox.

### SMTP

Simple Mail Transfer Protocol.

Used by the Mail Receiver adapter to send emails.

### STARTTLS

STARTTLS upgrades an existing connection to an encrypted TLS connection.

It is used to secure SMTP communication.

## 6. Important Notes

1.  Gmail requires appropriate account security configuration for IMAP
    and SMTP access.
2.  Use Gmail App Passwords where supported and permitted by account
    policies.
3.  Never upload passwords, App Passwords, or other credentials to
    GitHub.
4.  Configure the correct SMTP and IMAP server addresses and ports.
5.  When using the same Gmail account for Mail Sender and Mail Receiver,
    prevent repeated processing of emails generated by the receiver
    adapter.
6.  For production scenarios, implement appropriate authentication,
    error handling, monitoring, and email processing controls.
