# Project Overview

This project demonstrates how to consolidate regional sales records using **SAP Integration Suite – Cloud Integration (SAP CPI)**.

The integration flow receives sales data in JSON format, converts it into XML, separates individual regional records using General Splitter, combines the split messages using Gather, and calculates the total sales amount using a Groovy Script.

The final consolidated result is returned as a JSON response.

## Objective

- Receive regional sales data through an HTTPS endpoint.
- Convert incoming JSON data into XML.
- Split individual regional sales records.
- Combine split messages using Gather.
- Calculate total sales using Groovy Script.
- Generate a consolidated JSON response.

## Integration Flow Processing

### 1. HTTPS Sender

The HTTPS Sender Adapter receives the incoming sales data from an external application.

### 2. JSON to XML Converter

Converts the incoming JSON payload into XML format so that CPI can process individual records using XPath.

### 3. General Splitter

The General Splitter separates the regional sales records into individual messages.

For example:

- Message 1: South – 150000
- Message 2: North – 200000
- Message 3: West – 175000

### 4. Gather

Gather combines the individual messages generated by the General Splitter into a single consolidated XML message.

### 5. Groovy Script

The Groovy Script performs the following operations:

- Reads the XML payload received from Gather.
- Extracts the region names and sales amounts.
- Calculates the total sales amount.
- Skips incomplete or invalid sales records.
- Generates the final JSON response.

**Groovy Script:** `CalculateTotalSales.groovy`

## Total Sales Calculation

| Region | Sales |
|---|---:|
| South | 150000 |
| North | 200000 |
| West | 175000 |
| **Total Sales** | **525000** |

Calculation:

```text
TotalSales = 150000 + 200000 + 175000
TotalSales = 525000
```

## Error Handling

The Groovy Script includes basic handling for incomplete and invalid records.

- Missing region names are skipped.
- Missing sales values are skipped.
- Non-numeric sales values are skipped.
- If no valid records are available, TotalSales returns 0 and Regions returns an empty array.
